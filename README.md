# UDI Test Data

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23076190.svg)](https://doi.org/10.5281/zenodo.23076190)

Device identifier, lot, and serial strings in the GS1 element-string shape used by UDI carriers. Synthetic devices; not real products.

Free to use under **CC0-1.0** (public domain dedication, no attribution required).

DOI: [10.5281/zenodo.23076190](https://doi.org/10.5281/zenodo.23076190)

## Files

- `udi-small.json`
- `udi-small.csv`
- `udi-medium.json`
- `udi-medium.csv`
- `udi-large.json`
- `udi-large.csv`

Each size ships as JSON and CSV. The data is deterministic: the same size always
produces the same rows.
